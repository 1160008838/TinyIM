# TinyIM 使用说明书

## 1. 软件简介

TinyIM 是一款**无服务器、局域网点对点**的即时通讯软件，支持：
- ✅ 自动发现局域网内的设备
- ✅ 文字、图片、文件、语音消息
- ✅ 单聊和群聊
- ✅ 聊天历史记录
- ✅ 无需注册登录
- ✅ 数据完全本地存储

## 2. 安装与启动

### 2.1 Windows 版本

1. 下载 `TinyIM-Setup.exe` 或 `TinyIM.exe`
2. 双击运行安装程序（如使用安装版）
3. 安装完成后，从开始菜单或桌面启动 TinyIM
4. 首次启动会自动生成设备ID和默认昵称

### 2.2 Android 版本

1. 下载 `TinyIM.apk`
2. 在设置中允许"未知来源"应用安装
3. 点击APK文件安装
4. 打开 TinyIM 应用
5. 授予必要权限（网络、存储、相机、麦克风）

### 2.3 iOS 版本

1. 通过 TestFlight 或企业分发安装
2. 信任开发者证书（设置 -> 通用 -> 设备管理）
3. 打开 TinyIM 应用
4. 授予必要权限

### 2.4 Linux 版本

```bash
# 下载并添加执行权限
chmod +x TinyIM
./TinyIM
```

## 4. 核心功能使用

### 4.1 设备发现与连接

#### 自动发现
1. 确保设备连接到**同一局域网**（同一WiFi或有线网络）
2. 启动 TinyIM
3. 等待3-5秒，软件自动扫描并显示在线设备
4. 在"联系人"列表中查看所有在线设备

#### 手动刷新
- 下拉联系人列表刷新
- 或点击刷新按钮

### 4.2 发送消息

#### 发送文字消息
1. 在联系人列表中选择一个设备
2. 在底部输入框输入文字
3. 按回车或点击发送按钮

#### 发送图片
1. 点击输入框左侧的"图片"图标
2. 选择拍照或从相册选择
3. 确认后自动发送

#### 发送文件
1. 点击"文件"图标
2. 浏览并选择文件（无大小限制）
3. 确认发送，显示传输进度

#### 发送语音
1. 长按"语音"按钮开始录音
2. 松开按钮发送
3. 上滑取消发送

#### 发送表情
1. 点击"表情"图标
2. 选择内置表情
3. 点击发送

### 4.3 群聊功能

#### 创建群组
1. 点击"新建群聊"按钮
2. 从在线设备中选择成员（可多选）
3. 输入群名称
4. 点击"创建"

#### 群聊发送消息
- 与单聊相同，选择群组后发送即可
- 消息会自动分发给所有群成员

#### @提醒功能
1. 在群聊输入框中输入 `@`
2. 选择要@的成员
3. 继续输入消息内容

#### 群管理
- **查看群成员**: 点击群名称
- **添加成员**: 群详情 -> 添加成员
- **移除成员**: 群详情 -> 长按成员 -> 移除（仅创建者）
- **退出群聊**: 群详情 -> 退出群聊
- **编辑群公告**: 群详情 -> 编辑公告

### 4.4 语音/视频通话

#### 发起语音通话
1. 打开与对方的聊天窗口
2. 点击右上角"语音通话"图标
3. 等待对方接听

#### 发起视频通话
1. 打开与对方的聊天窗口
2. 点击右上角"视频通话"图标
3. 等待对方接听

#### 通话中操作
- **静音**: 点击麦克风图标
- **挂断**: 点击红色挂断按钮
- **切换摄像头**: 点击摄像头切换图标（仅视频）

#### 视频会议（群组）
1. 在群聊中点击"视频会议"
2. 邀请群成员加入
3. 成员陆续加入后开始会议
4. 支持多人同屏显示

### 4.5 聊天历史

#### 查看历史记录
- 进入聊天窗口，自动加载最近50条消息
- 向上滚动自动加载更早的消息

#### 搜索消息
1. 点击聊天窗口的"搜索"图标
2. 输入关键词
3. 查看匹配结果

#### 删除消息
- **单条删除**: 长按消息 -> 删除
- **批量删除**: 进入选择模式 -> 勾选 -> 删除
- **清空记录**: 聊天详情 -> 清空聊天记录

#### 撤回消息
1. 长按自己发送的消息
2. 选择"撤回"
3. 对方端同步显示"撤回了一条消息"

### 4.6 文件管理

#### 查看已接收文件
1. 进入"我的" -> "文件管理"
2. 查看所有接收的文件列表
3. 点击打开或分享

#### 自定义保存路径
1. 进入"我的" -> "设置" -> "文件保存位置"
2. 选择图片、文件、语音、视频的保存目录
3. 保存设置

## 5. 个人设置

### 5.1 修改个人信息

1. 进入"我的"页面
2. 点击头像或昵称
3. 修改昵称：直接输入新昵称
4. 修改头像：选择照片或拍照

### 5.2 查看设备信息

在"我的" -> "关于"中查看：
- 设备唯一ID
- 本机IP地址
- 软件版本号

### 5.3 联系人管理

#### 添加备注名
1. 长按联系人
2. 选择"设置备注"
3. 输入备注名（仅自己可见）

#### 消息通知设置
- **单个联系人**:
  1. 进入聊天详情
  2. 开启/关闭"消息通知"
  
- **全局设置**:
  1. 进入"我的" -> "设置" -> "通知"
  2. 开启/关闭消息提示音
  3. 开启/关闭震动

### 5.4 系统设置

#### 语言切换
1. 进入"我的" -> "设置" -> "语言"
2. 选择中文简体或English

#### 主题设置（可选功能）
1. 进入"我的" -> "设置" -> "主题"
2. 选择浅色或深色主题

#### 隐私设置
- **允许/拒绝设备列表**: 设置允许通信的设备白名单

## 6. 常见问题 FAQ

### Q1: 找不到其他设备怎么办？

**A**: 请检查：
1. 是否连接到同一局域网（WiFi或有线）
2. 防火墙是否阻止了 TinyIM（需允许端口 5353 和 9527）
3. 尝试手动刷新设备列表
4. 重启 TinyIM 应用

### Q2: 消息发送失败怎么办？

**A**: 可能原因：
1. 对方设备离线
2. 网络连接不稳定
3. 防火墙阻止通信
4. 尝试重新发送

### Q3: 如何保证聊天记录不丢失？

**A**: 
1. 聊天记录自动保存在本地数据库
2. 定期备份数据库文件（位于 `~/.tinyim/tinyim.db`）
3. 卸载前导出聊天记录

### Q4: 可以在不同网络间使用吗？

**A**: 不可以。TinyIM 仅支持局域网内通信，不支持广域网（互联网）。

### Q5: 如何确保数据安全？

**A**: 
1. 所有数据仅保存在本地设备
2. 不上传到云端或服务器
3. 可选：启用端到端加密（高级设置）

### Q6: 支持哪些文件格式？

**A**: 支持所有格式的文件，无大小限制（受限于网络速度）。

### Q7: 如何更新软件？

**A**: 
1. 检查"关于"页面的版本号
2. 下载最新版本安装包
3. 覆盖安装（数据不会丢失）

### Q8: 卸载后数据还在吗？

**A**: 
- Windows/Linux: 数据保存在用户目录，卸载后仍保留
- Android/iOS: 卸载会删除所有数据，请提前备份

## 8. 性能提示

### 提高传输速度
1. 使用有线网络连接
2. 减少同时传输的文件数量
3. 关闭不必要的后台应用

### 节省存储空间
1. 定期清理聊天记录
2. 压缩图片后发送
3. 删除不需要的文件

### 减少电量消耗（移动端）
1. 关闭不必要的消息通知
2. 不使用时退出应用
3. 降低屏幕亮度
